# Simple Interest Calculator

This repository is the final project for **Getting Started with Git and GitHub** (IBM/Coursera). It contains a Bash script that calculates simple interest from a principal amount, an annual interest rate, and a time period in years.

## Input

- `p`: principal amount
- `r`: annual rate of interest, entered as a percentage (for example, `5` means 5%)
- `t`: time period in years

## Output

The simple interest is calculated using:

```text
simple interest = (p * t * r) / 100
```

For example, with a principal of 1000, an annual rate of 5%, and a period of 2 years, the simple interest is 100.

## How to run

Open a Bash terminal, go to the repository directory, and run:

```bash
bash simple-interest.sh
```

Enter the three requested values when prompted.
