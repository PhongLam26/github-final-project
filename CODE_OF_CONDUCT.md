# Code of Conduct

## Our Pledge

We pledge to make participation in this project a welcoming, respectful, and harassment-free experience for everyone, regardless of background, identity, experience, or ability.

## Our Standards

Positive behavior includes using inclusive language, respecting different viewpoints, accepting constructive criticism, and showing empathy toward other community members.

Unacceptable behavior includes harassment, insults, personal attacks, discrimination, publishing someone's private information without permission, and inappropriate conduct in a professional community.

## Enforcement Responsibilities

Project maintainers are responsible for clarifying these standards, investigating reported violations fairly, and taking appropriate corrective action. Maintainers may remove or edit comments, commits, or other contributions that violate these standards.

## Scope

This Code of Conduct applies to all project spaces, including issues, pull requests, and discussions. It also applies when someone publicly represents this project.

## Enforcement

Report unacceptable behavior privately through the repository maintainer's GitHub profile or GitHub's reporting tools. Reports will be reviewed promptly, with attention to privacy and fairness. Do not include private personal information in a public issue.

## Enforcement Guidelines

Maintainers may use these guidelines depending on the seriousness and impact of an incident:

1. **Correction:** A private warning and explanation of the behavior expected.
2. **Warning:** A formal warning for inappropriate behavior, with clear limits on further interaction.
3. **Temporary restriction:** Temporary exclusion from participating in project discussions or contributions.
4. **Permanent restriction:** Removal from the project community for serious or repeated violations.
